# StoryGraph Reading Analysis
A data analysis of my reading habits, based on a 3-year StoryGraph export.

## Main Questions
- How many books do I read per month on average?
- Does the length of a book affect its rating? 
- Are there months in which I read more or fewer books?
- How do the length and ratings of my books differ between the languages I read in?

## Data
My data comes from a StoryGraph export of books I have read over the last 3 years. The raw CSV with book titles and other data is personal and won’t be included.

## Tools
Python, pandas, matplotlib, seaborn, Jupyter

## Setup
```bash
git clone https://github.com/saguato/storygraph-analysis.git
cd storygraph-analysis
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
